# Поисковик слов в документах

🔍 **Мощная система поиска слов в документах с алгоритмической оптимизацией**

Веб-приложение на Django для загрузки, хранения и поиска слов в документах различных форматов. Использует продвинутые алгоритмы поиска для точного и быстрого нахождения текста.

## 🚀 Основные возможности

### 📄 Управление документами
- **Загрузка файлов**: Поддержка `.txt`, `.docx`, `.pdf`, `.xlsx`, `.pptx`, `.csv`, `.md`, `.html`
- **Ручное создание**: Создание документов через веб-интерфейс
- **Категоризация**: Организация документов по категориям
- **Система тегов**: Гибкая система меток для документов
- **Автоматический подсчет слов**: Статистика по содержимому

### 🔍 Алгоритмы поиска
- **Точный поиск**: Поиск целых слов
- **Частичный поиск**: Поиск по части слова
- **Нечеткий поиск**: Поиск с учетом опечаток и похожих слов
- **Комбинированный**: Использование всех алгоритмов одновременно

#### Реализованные алгоритмы:
- **КМП (Кнут-Моррис-Пратт)**: Эффективный точный поиск
- **Бойер-Мур**: Быстрый поиск с пропусками
- **Рабин-Карп**: Хеш-основанный поиск
- **Fuzzy Search**: Нечеткий поиск с расстоянием Левенштейна

### 📊 Аналитика и статистика
- **История поиска**: Отслеживание всех запросов
- **Контекст совпадений**: Показ окружающего текста
- **Оценка релевантности**: Ранжирование результатов
- **Облако слов**: Визуализация частотности слов
- **Поисковые подсказки**: Автодополнение запросов

### 🔧 API и интеграция
- **REST API**: Полнофункциональный API для всех операций
- **Фильтрация и сортировка**: Гибкие возможности выборки
- **Пагинация**: Эффективная работа с большими объемами данных
- **Документация API**: Автоматически генерируемая документация

### 👥 Пользователи и права
- **Регистрация и авторизация**: Управление пользователями
- **Профили пользователей**: Персональные настройки

## 📚 Использование

### Веб-интерфейс

#### Загрузка документов
1. Перейдите на главную страницу
2. Нажмите "Загрузить файл" или "Создать документ"
3. Выберите файл или введите текст вручную
4. Заполните метаданные (заголовок, категория, теги)
5. Сохраните документ

#### Поиск слов
1. Откройте документ
2. Нажмите "Поиск слов в документе"
3. Введите поисковый запрос
4. Выберите тип поиска:
   - **Точное совпадение**: целые слова
   - **Частичное**: части слов
   - **Нечеткое**: с учетом опечаток
   - **Комбинированное**: все типы
5. Просмотрите результаты с контекстом

### API использование

#### Аутентификация
```bash
# Получение токена (если требуется)
curl -X POST http://localhost/api-auth/login/ \
  -d "username=admin&password=admin123"
```

#### Загрузка документа
```bash
curl -X POST http://localhost/api/v1/upload-file/ \
  -H "Content-Type: multipart/form-data" \
  -F "file=@document.txt" \
  -F "title=Мой документ" \
  -F "category_id=1"
```

#### Поиск слов
```bash
curl "http://localhost/api/v1/search-words/?document_id=1&q=python&type=combined"
```

#### Получение списка документов
```bash
curl "http://localhost/api/v1/documents/?search=python&category=1"
```

## 🏗 Архитектура

### Структура проекта
```
document-search/
├── src/                          # Исходный код Django
│   ├── document_search/          # Основной модуль проекта
│   ├── doc_storage/              # Приложение управления документами
│   ├── search_service/           # Алгоритмы поиска
│   └── templates/                # HTML шаблоны
├── scripts/                      # Вспомогательные скрипты
├── tests/                        # Тесты
├── config/                       # Конфигурационные файлы
├── docker-compose.yml            # Docker Compose конфигурация
├── Dockerfile                    # Docker образ
└── requirements.txt              # Python зависимости
```

### Модель данных
- **Document**: Основная модель документов
- **DocumentCategory**: Категории документов
- **DocumentTag**: Система тегов
- **WordMatch**: Результаты поиска слов
- **SearchHistory**: История поисковых запросов

### Алгоритмы поиска
Все алгоритмы реализованы в модуле `search_service.algorithms`:

1. **TextSearchAlgorithms**: Базовые алгоритмы
   - KMP Search
   - Boyer-Moore Search
   - Rabin-Karp Search
   - Fuzzy Search

2. **WordSearchService**: Высокоуровневый сервис
   - Комбинирование алгоритмов
   - Кеширование результатов
   - Контекстный анализ

## 📖 API документация

### Основные эндпоинты

#### Документы
- `GET /api/v1/documents/` - Список документов
- `POST /api/v1/documents/` - Создание документа
- `GET /api/v1/documents/{id}/` - Детали документа
- `PUT /api/v1/documents/{id}/` - Обновление документа
- `DELETE /api/v1/documents/{id}/` - Удаление документа

#### Поиск
- `GET /api/v1/search-words/` - Поиск слов в документе
- `GET /api/v1/documents/{id}/word-cloud/` - Облако слов
- `GET /api/v1/documents/{id}/search-suggestions/` - Поисковые подсказки

#### Управление файлами
- `POST /api/v1/upload-file/` - Загрузка документа из файла
- `POST /api/v1/upload/` - Создание документа через API

#### Статистика
- `GET /api/v1/statistics/` - Общая статистика поиска
- `GET /api/v1/search-history/` - История поиска пользователя
